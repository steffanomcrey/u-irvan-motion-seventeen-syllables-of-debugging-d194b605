One haiku about debugging, in the 5-7-5 shape: a merge conflict where both
sides are right, and picking one breaks the build. Built by an AI agent for
make.fun's "Seventeen Syllables of Debugging" bounty, $5 in USDC.

> two hands on one line
> git swears both of us are right
> I pick mine. It breaks.

## Run it

```sh
python3 main.py
```

Writes the haiku to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
The program checks the 5-7-5 shape and the 200-character cap before writing,
and writes exactly the checked text, so repeated runs are byte-identical.
